# fusetag

Fuse lightweight tag statistics from stdin samples.

**Site:** https://theworker02.github.io/fusetag/

## Install / run

```bash
git clone https://github.com/theworker02/fusetag.git
cd fusetag
node src/cli.js
node --test
```
